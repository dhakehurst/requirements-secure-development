# Instructions for Code Agents

This repository holds requirement texts, not code. Before changing anything, read
[MAINTAINING.md](MAINTAINING.md): its decisions (section 4) and editing rules (section 5) apply to
every change.

- Run `python3 tools/check.py` before you commit; it must pass.
- Never reuse or renumber an id. Retire a requirement instead (MAINTAINING.md, section 5).
- Never add the name of a person, company, customer, programme, product or sector that uses the
  sets, and never cite a sector-specific standard.
- Do not reverse a decision in MAINTAINING.md section 4 without the owner's approval, and record
  the new reason there.
- Check a source on its publisher's page before citing it or changing its edition, and update the
  source table (MAINTAINING.md, section 3) with the date you checked it.
- Write British English and wrap lines at 100 characters (tables and code blocks excepted).
